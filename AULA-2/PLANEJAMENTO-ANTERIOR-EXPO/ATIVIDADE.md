# Atividade — Meu primeiro projeto Expo

**Formato:** individual ou em duplas, conforme os equipamentos.  
**Objetivo:** criar e executar a base do aplicativo, localizar arquivos e verificar uma alteração.  
**Apoio:** utilizar o passo a passo de [CONTEUDO.md](CONTEUDO.md).

## Parte 1 — Preparar

1. Abrir o terminal e conferir as versões do Node.js e do npm.
2. Escolher a pasta onde ficará o aplicativo.
3. Criar o projeto `eventos-mobile`, seguindo o modelo utilizado pelo professor.
4. Abrir a pasta do projeto no editor.

Registrar o caminho da pasta e as versões retornadas. Em duplas, alternar quem opera o computador a cada etapa.

## Parte 2 — Executar

1. Iniciar o servidor dentro da pasta do aplicativo.
2. Abrir o projeto no dispositivo disponível.
3. Conferir se a interface inicial aparece.
4. Registrar a plataforma utilizada: Android, iOS ou web.

Caso ocorra um bloqueio, anotar o comando executado, a mensagem do erro e o que já foi tentado. Solicitar apoio sem apagar o projeto ou reinstalar todas as ferramentas por tentativa.

## Parte 3 — Explorar e modificar

1. Localizar `package.json` e identificar a versão declarada do pacote `expo`.
2. Localizar o arquivo da tela inicial utilizada pelo projeto.
3. Alterar um texto para “Meu primeiro aplicativo de eventos”.
4. Incluir o nome dos integrantes no mesmo texto.
5. Salvar e verificar a mudança na aplicação.
6. Encerrar o servidor e iniciá-lo novamente na mesma pasta.

## Parte 4 — Explicar

Responder com suas palavras:

1. Para que serve o terminal nesta prática?
2. Qual comando criou o projeto? Qual iniciou o servidor?
3. Qual é o caminho do arquivo que vocês editaram?
4. O que o `package.json` permite identificar?
5. Executar pelo Expo Go significa publicar nas lojas? Explique.
6. Qual dificuldade ocorreu e como foi investigada?

## Entrega

- Nome dos integrantes.
- Versões do Node.js, npm e versão declarada de `expo`.
- Caminho da pasta e do arquivo editado.
- Captura da tela modificada, indicando a plataforma, ou demonstração ao professor.
- Respostas da parte 4.
- Registro de pendências, caso a execução não tenha sido concluída.

Preservar a pasta do aplicativo para a aula 3. Não é necessário entregar a pasta `node_modules` nem compartilhar credenciais de contas.

## Critérios de acompanhamento do professor

| Critério | Evidência |
|---|---|
| Organização | Localiza a pasta e abre o terminal no lugar correto. |
| Execução | Demonstra o aplicativo e informa a plataforma utilizada. |
| Alteração | Mostra o texto modificado e identifica o arquivo. |
| Compreensão | Distingue criação, execução e edição do projeto. |
| Investigação | Descreve dificuldades e verificações realizadas. |

Usar os critérios de forma diagnóstica, sem peso de nota previamente definido. Quando houver bloqueio de infraestrutura, registrar a execução como pendente e avaliar separadamente o entendimento demonstrado.
