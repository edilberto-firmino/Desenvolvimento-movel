07 é Criar a tabela e entender as consultas

Leia este SQL antes de copiar os arquivos. Estes exemplos explicam o que database.js executará; não são comandos para colar no PowerShell.

SQL é estrutura da tabela
CREATE TABLE IF NOT EXISTS eventos (
  id INTEGER PRIMARY KEY NOT NULL,
  nome TEXT NOT NULL CHECK(length(trim(nome)) > 0),
  local TEXT NOT NULL CHECK(length(trim(local)) > 0)
);
  • IF NOT EXISTS permite iniciar o app novamente sem recriar uma tabela já existente.
  • INTEGER PRIMARY KEY permite ao SQLite atribuir um identificador quando não informamos id no INSERT. Não presuma ids consecutivos ou nunca reutilizados.
  • NOT NULL impede valor nulo; o CHECK também impede texto vazio ou só com espaços.
  • Nome e local são texto. Eventos de nomes iguais são permitidos e continuam tendo ids distintos.
SQL é quatro operações (os é recebem os valores pelo JavaScript)
INSERT INTO eventos (nome, local) VALUES (ç, ç);
SELECT id, nome, local FROM eventos ORDER BY id DESC;
UPDATE eventos SET nome = ç, local = ç WHERE id = ç;
DELETE FROM eventos WHERE id = ç;
A ordem dos parâmetros deve corresponder à ordem dos pontos de interrogação. Nunca monte SQL concatenando o texto digitado. O WHERE limita alteração e exclusão ao id selecionado; sem ele, todas as linhas seriam afetadas. Não experimente remover WHERE no banco com sua entrega.

Pergunta é turma: se o nome contém apóstrofo, como “Feira d’Ideias”, o que acontece? Com parâmetros, esse texto é um valor, não uma parte do comando SQL.

Este arquivo concentra a conexão e o SQL. Copie tudo para database.js na raiz do aplicativo. Ele não contém JSX nem componentes visuais.

database.js
Baixar arquivo
import * as SQLite from 'expo-sqlite';

let conexao;

export async function abrirBanco() {
  if (!conexao) {
    conexao = SQLite.openDatabaseAsync('eventos-campus.db').catch((erro) => {
      conexao = undefined;
      throw erro;
    });
  }
  return conexao;
}

export async function prepararBanco() {
  const db = await abrirBanco();
  // Somente SQL fixo aqui. Nunca interpolar o texto do formulário.
  await db.execAsync(`
    CREATE TABLE IF NOT EXISTS eventos (
      id INTEGER PRIMARY KEY NOT NULL,
      nome TEXT NOT NULL CHECK(length(trim(nome)) > 0),
      local TEXT NOT NULL CHECK(length(trim(local)) > 0)
    );
  `);
}

export async function listarEventos() {
  const db = await abrirBanco();
  return db.getAllAsync('SELECT id, nome, local FROM eventos ORDER BY id DESC;');
}

export async function salvarEvento(id, nome, local) {
  const db = await abrirBanco();
  if (id === null) {
    return db.runAsync('INSERT INTO eventos (nome, local) VALUES (?, ?);', nome, local);
  }
  return db.runAsync('UPDATE eventos SET nome = ?, local = ? WHERE id = ?;', nome, local, id);
}

export async function excluirEvento(id) {
  const db = await abrirBanco();
  return db.runAsync('DELETE FROM eventos WHERE id = ?;', id);
}

09 é Código completo de App.js

Substitua todo o conteúdo de App.js. A tela usa formulário controlado, mensagens, lista com rolagem e confirmação de exclusão. O arquivo mantém a lógica visível para facilitar a leitura em aula.

App.js
Baixar arquivo
import { useEffect, useRef, useState } from 'react';
import { Alert, FlatList, Keyboard, KeyboardAvoidingView, Platform, Pressable, Text, TextInput, View } from 'react-native';
import { SafeAreaProvider, SafeAreaView } from 'react-native-safe-area-context';
import { prepararBanco, listarEventos, salvarEvento, excluirEvento } from './database';
import styles from './styles';

export default function App() {
  const [eventos, setEventos] = useState([]);
  const [nome, setNome] = useState('');
  const [local, setLocal] = useState('');
  const [editandoId, setEditandoId] = useState(null);
  const [pronto, setPronto] = useState(false);
  const [ocupado, setOcupado] = useState(false);
  const [mensagem, setMensagem] = useState('Abrindo banco...');
  // A trava impede dois toques de iniciar gravações simultâneas.
  const trava = useRef(false);
  const listaRef = useRef(null);

  async function iniciar() {
    if (trava.current) return;
    trava.current = true;
    setOcupado(true);
    setPronto(false);
    try {
      await prepararBanco();
      setEventos(await listarEventos());
      setPronto(true);
      setMensagem('Banco pronto. Cadastre seu primeiro evento ou consulte a lista.');
    } catch (erro) {
      console.error(erro);
      setMensagem('Não foi possível abrir o banco. Confira o terminal e tente novamente.');
    } finally {
      trava.current = false;
      setOcupado(false);
    }
  }

  useEffect(() => { iniciar(); }, []);

  function limparFormulario() {
    setEditandoId(null);
    setNome('');
    setLocal('');
  }

  async function salvar() {
    if (trava.current || !pronto) return;
    if (!nome.trim() || !local.trim()) {
      Alert.alert('Campos obrigatórios', 'Preencha nome e local do evento.');
      return;
    }
    trava.current = true;
    setOcupado(true);
    let gravou = false;
    try {
      await salvarEvento(editandoId, nome.trim(), local.trim());
      gravou = true;
      limparFormulario();
      Keyboard.dismiss();
      setEventos(await listarEventos());
      setMensagem('Evento salvo no SQLite.');
    } catch (erro) {
      console.error(erro);
      setMensagem(gravou
        ? 'Gravado, mas a lista não atualizou. Use Atualizar lista antes de cadastrar novamente.'
        : 'Não foi possível salvar. Confira o terminal e tente novamente.');
    } finally {
      trava.current = false;
      setOcupado(false);
    }
  }

  function editar(evento) {
    if (trava.current) return;
    setEditandoId(evento.id);
    setNome(evento.nome);
    setLocal(evento.local);
    setMensagem(`Editando evento #${evento.id}. Altere os campos e salve.`);
    listaRef.current?.scrollToOffset({ offset: 0, animated: true });
  }

  async function remover(id) {
    if (trava.current || !pronto) return;
    trava.current = true;
    setOcupado(true);
    let removeu = false;
    try {
      await excluirEvento(id);
      removeu = true;
      if (editandoId === id) limparFormulario();
      setEventos(await listarEventos());
      setMensagem('Evento excluído.');
    } catch (erro) {
      console.error(erro);
      setMensagem(removeu
        ? 'Excluído, mas a lista não atualizou. Use Atualizar lista.'
        : 'Não foi possível excluir. Confira o terminal.');
    } finally {
      trava.current = false;
      setOcupado(false);
    }
  }

  function confirmarExclusao(evento) {
    if (trava.current) return;
    Alert.alert('Excluir evento?', evento.nome, [
      { text: 'Cancelar', style: 'cancel' },
      { text: 'Excluir', style: 'destructive', onPress: () => remover(evento.id) },
    ]);
  }

  async function atualizar() {
    if (trava.current || !pronto) return;
    trava.current = true;
    setOcupado(true);
    try {
      setEventos(await listarEventos());
      setMensagem('Lista consultada novamente no banco.');
    } catch (erro) {
      console.error(erro);
      setMensagem('Falha ao consultar. Confira o terminal.');
    } finally {
      trava.current = false;
      setOcupado(false);
    }
  }

  const bloqueado = ocupado || !pronto;
  return (
    <SafeAreaProvider>
      <SafeAreaView style={styles.tela}>
        <KeyboardAvoidingView style={styles.tela} behavior={Platform.OS === 'ios' ? 'padding' : undefined}>
          <FlatList
            ref={listaRef}
            data={eventos}
            keyExtractor={(item) => String(item.id)}
            contentContainerStyle={styles.conteudo}
            keyboardShouldPersistTaps="handled"
            ListHeaderComponent={
              <View>
                <Text style={styles.selo}>AULA PRÁTICA 3 · SQLITE</Text>
                <Text style={styles.titulo}>Agenda do campus</Text>
                <Text style={styles.texto}>Eventos salvos neste aparelho.</Text>
                <Text accessibilityLiveRegion="polite" style={styles.mensagem}>{mensagem}</Text>
                {!pronto && !ocupado && <Pressable accessibilityRole="button" style={styles.botao} onPress={iniciar}><Text style={styles.botaoTexto}>Tentar abrir banco</Text></Pressable>}
                <View style={styles.cartao}>
                  <Text style={styles.subtitulo}>{editandoId === null ? 'Novo evento' : `Editar evento #${editandoId}`}</Text>
                  <Text style={styles.rotulo}>Nome do evento</Text>
                  <TextInput accessibilityLabel="Nome do evento" style={styles.input} value={nome} onChangeText={setNome} editable={!bloqueado} maxLength={100} placeholder="Ex.: Oficina de aplicativos" />
                  <Text style={styles.rotulo}>Local</Text>
                  <TextInput accessibilityLabel="Local do evento" style={styles.input} value={local} onChangeText={setLocal} editable={!bloqueado} maxLength={100} placeholder="Ex.: Laboratório 2" />
                  <Pressable accessibilityRole="button" accessibilityState={{ disabled: bloqueado }} disabled={bloqueado} onPress={salvar} style={[styles.botao, bloqueado && styles.desabilitado]}>
                    <Text style={styles.botaoTexto}>{ocupado ? 'Aguarde...' : editandoId === null ? 'Salvar evento' : 'Salvar alterações'}</Text>
                  </Pressable>
                  {editandoId !== null && <Pressable accessibilityRole="button" disabled={bloqueado} onPress={limparFormulario} style={styles.secundario}><Text style={styles.link}>Cancelar edição</Text></Pressable>}
                </View>
                <Text style={styles.subtitulo}>Eventos cadastrados ({eventos.length})</Text>
                <Pressable accessibilityRole="button" disabled={bloqueado} onPress={atualizar} style={styles.secundario}><Text style={styles.link}>Atualizar lista</Text></Pressable>
              </View>
            }
            ListEmptyComponent={<Text style={styles.texto}>{pronto ? 'Nenhum evento cadastrado.' : 'Aguardando o banco.'}</Text>}
            renderItem={({ item }) => (
              <View style={styles.cartao}>
                <Text style={styles.selo}>EVENTO #{item.id}</Text>
                <Text style={styles.subtitulo}>{item.nome}</Text>
                <Text style={styles.texto}>Local: {item.local}</Text>
                <View style={styles.acoes}>
                  <Pressable accessibilityRole="button" accessibilityLabel={`Editar ${item.nome}`} disabled={bloqueado} style={styles.secundario} onPress={() => editar(item)}><Text style={styles.link}>Editar</Text></Pressable>
                  <Pressable accessibilityRole="button" accessibilityLabel={`Excluir ${item.nome}`} disabled={bloqueado} style={styles.secundario} onPress={() => confirmarExclusao(item)}><Text style={styles.excluir}>Excluir</Text></Pressable>
                </View>
              </View>
            )}
            ListFooterComponent={<Text style={styles.rodape}>INBEC · Sua turma / seus nomes aqui</Text>}
          />
        </KeyboardAvoidingView>
      </SafeAreaView>
    </SafeAreaProvider>
  );
}

11 é Entender conexão, estado e fluxo dos dados

1. Abrir não é criar uma tabela

openDatabaseAsync abre ou cria eventos-campus.db. A variável conexao guarda a promessa da conexão para reutilizá-la durante a execução. Se a abertura falhar, ela é limpa para permitir nova tentativa. prepararBanco cria a tabela antes da primeira consulta; abrir o arquivo sozinho não define suas colunas.

2. Esperar o banco antes de habilitar o formulário

useEffect chama iniciar na montagem. A função aguarda prepararBanco e listarEventos. Só então pronto fica verdadeiro. Em falha, o usuário vê uma mensagem e o botão Tentar abrir banco. Não feche a conexão depois de cada consulta: o exemplo a reutiliza durante a sessão.

3. Campos controlados e identificador da edição

useState guarda nome, local, eventos, editandoId e mensagens. Cada TextInput recebe value e onChangeText. O id nulo representa novo cadastro; ao editar, guardamos o id do registro. Cancelar edição limpa o formulário sem alterar o banco.

4. Gravar, consultar e renderizar

Toque em Salvar é validar com trim é aguardar INSERT ou UPDATE é limpar formulário é executar SELECT é setEventos é React atualiza a FlatList. Alterar apenas setEventos muda a tela, mas não grava dados no SQLite.

5. Operações assíncronas e erros

async/await organiza a sequência de operações. try/catch mostra falhas e console.error deixa detalhes no terminal. finally libera a interface. ocupado desabilita os controles; useRef mantém uma trava imediata contra dois toques antes da próxima renderização. Se a gravação ocorrer e só a consulta falhar, a mensagem orienta atualizar a lista para não cadastrar de novo.

6. Uma lista e uma identidade

FlatList usa String(item.id) como chave. Não usamos o nome, que pode se repetir. Editar carrega os campos e rola ao formulário. Excluir abre Alert: Cancelar não modifica o banco e Excluir chama a função com o id selecionado. A lista usa um cabeçalho com formulário para manter a rolagem em uma única Área.

7. O que fica para depois

Este exemplo cria uma tabela inicial. Se mudar suas colunas, CREATE TABLE IF NOT EXISTS não atualiza a tabela existente. Evoluções reais exigem migrações versionadas, por exemplo com PRAGMA user_version e ALTER TABLE. Backup, sincronização, autenticação e criptografia não são implementados nesta aula.

  2. Deixe texto digitado no formulário sem salvar.

15 é Experimentos guiados e desafio

  1. Ordenação: troque ORDER BY id DESC por ORDER BY nome COLLATE NOCASE ASC. Use Atualizar lista e compare. A ordem é definida pela consulta, não pela posição física das linhas.
  2. Persistência: troque só uma cor em styles.js e recarregue. Os dados devem continuar presentes.
  3. Validação: tente campos com espaços e explique por que trim é usado antes de salvar.
  4. Identidade: cadastre dois eventos de mesmo nome e edite apenas um. Compare os ids.
  5. Leitura: acrescente temporariamente console.log ao retorno da consulta e observe a lista de objetos no terminal. Retire o log ao finalizar.
Desafio opcional: pesquisar eventos pelo nome

Crie uma função buscarEventos no database.js e use a consulta abaixo com db.getAllAsync, passando '%' + termo.trim() + '%' como parâmetro. Na tela, acrescente estado para termo e um TextInput de pesquisa. Execute a busca por botão, usando a mesma trava e o tratamento de erro de atualizar. Termo vazio deve listar todos.

SQL é busca parametrizada
SELECT id, nome, local FROM eventos WHERE nome LIKE ç ORDER BY id DESC;

O parâmetro evita concatenar entrada ao SQL; os símbolos % e _ continuam tendo significado de curingas no LIKE. Teste uma pesquisa com e sem resultado. Este desafio não exige alterar a estrutura da tabela.

Adicionar data como coluna fica para uma aula de migrações: não basta inserir a propriedade no objeto React e esperar que o banco existente se altere sozinho.
