# Aula 3 — Componentes básicos e primeira tela

Planejamento da terceira aula de **Dispositivos Móveis**, com React Native e Expo.

**Resultado esperado:** montar uma tela com `View`, `Text`, `Image` e `Pressable`, apresentando um evento fictício e uma ação de demonstração.

## Materiais

- [Plano de aula](PLANO-DE-AULA.md): objetivos, preparação e roteiro do professor.
- [Conteúdo](CONTEUDO.md): explicações e exemplo completo para a prática.
- [Atividade](ATIVIDADE.md): exercício, entrega e critérios de acompanhamento.

## Continuidade

Utilizar o projeto criado na aula 2. A duração segue ajustável ao encontro, e a prática pode ser individual ou em duplas. Estilos aparecem apenas como apoio à leitura da tela; layouts com Flexbox serão aprofundados na aula 4.

Esta pasta guarda materiais de planejamento. O exemplo deve ser aplicado no projeto dos alunos, não executado como aplicativo independente nesta pasta.

Referências oficiais consultadas em 23/09/2026. O código é um exemplo didático para ensaio no projeto da turma; não foi executado em um celular durante a preparação deste material.
